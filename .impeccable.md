## Design Context

### Users
The primary user runs this userscript for long periods while managing API routing on
KFCoding or AIHub. The interface must also be understandable to a first-time user
without hiding the controls that experienced users operate frequently.

### Brand Personality
Quiet, operational, and exact. The panel should feel like a maintained engineering
tool, not a marketing dashboard or an AI-generated concept UI. Confidence should come
from clear state, aligned data, and predictable controls.

### Aesthetic Direction
Use a compact, system-native operator console with restrained light and dark themes.
Prefer platform typography, familiar controls, small radii, tabular numbers, and one
muted green action accent. Translucency belongs only to functional chrome such as the
toolbar, navigation, menus, and dialogs. Avoid glow, gradients, decorative glass,
oversized metrics, card grids, pill-heavy UI, and motion that does not communicate state.

Design dials: variance 3/10, motion 1/10, density 8/10.

### Design Principles
1. Keep monitoring, routing settings, and diagnostics as distinct, predictable workspaces.
2. Put current routing state, daily usage, and immediate actions ahead of configuration.
3. Use spacing and separators for hierarchy; use containers only for real boundaries.
4. Keep technical values stable with tabular figures and compact labels.
5. Design dark, light, desktop, mobile, reduced-motion, and reduced-transparency states together.
6. Respond immediately to pointer input and preserve keyboard navigation and focus state.
