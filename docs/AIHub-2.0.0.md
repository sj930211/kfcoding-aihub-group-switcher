# AIHub 分组工作台 2.0.0

本地实现版本：2.0.0。依据已确认的 AIHUB-DESIGN-2；发布、安装和用户验收状态以任务报告为准。

## 运行范围与升级

- 仅在 https://aihub.top/ 启动。KFCoding、ooioo、FluxionAI 的旧本地数据保留，但插件不再在这些站点运行。
- 保留 userscript 的旧 name 和 namespace，避免改变已有安装身份；版本由 package.json.version 构建。
- 旧省钱、稳定、均衡策略统一迁移为 quality。保留正常择优/仅故障转移、确认次数、保持时间、消费提醒、主题及密钥选择。
- 图片评价、评分密钥、备用评分组、图片准入和相关配置已删除。刷新、检测和切组不发起付费模型推理；AIHub 的站点检测图片仅供查看。

## 监控分组

在“设置 → 自动切换 → 监控分组”选择全部或指定组。可按名称、ID、平台、模型搜索；筛选保留隐藏选择。只有点击“保存监控范围”才保存，保存本身不检查、不切组，并取消旧确认。指定模式下空列表表示不监控任何组。

刷新、计划检查、推荐、正常切换和故障恢复只处理所选ID。公开 providers 接口目前返回全站目录，因此减少的是本地评估和展示，不代表只下载所选组。白/黑名单和模型支持继续约束自动候选。

当前密钥在范围外时暂停自动检查和切换。提示支持加入监控或移除选择；移除只取消插件勾选，不删除、吊销或改动AIHub账户密钥。

旧 businessPlatform 未指定时迁移为全部。指定了平台但尚未取得完整目录/平台字段时保持待迁移和暂停；可完整映射后转为指定组ID，不扩大到全部。新范围优先于旧平台；新组不会自动加入指定范围。普通主题、保护等设置保存不得清除待迁移信息。

手动目标可从完整目录选择，只检查当前组和明确目标，结果不替换监控首页。越界提供“加入监控并切换 / 仅切换一次 / 取消”。不合格目标需要显式风险确认；旧结果通过但刷新后失败时，先展示最新风险再确认。单次覆盖不改变范围，切换后若在范围外自动处理暂停。

## 检测详情准入

每组只使用详情 model 与启用模型精确匹配的指标，其余模型本轮不参与。要求该组实际支持此模型。

自动候选须为 v2、1h 数据；成功率、缓存命中、TPS与样本有效，模型样本及缓存 usage_records 默认分别至少10，成功率默认至少95%。providers.generated_at 和缓存 refreshed_at 必须有效、非未来、60分钟内；缓存 ready=true 且 stale=false。缺失不补零，不回退旧窗口算法。

检测要求 applicable=true、status=passed、execution_complete=true、presentation.text.result=true；每个显式启用阶段必须存在、完成并通过。刷新、失败、疑似、证据不足、缺详情/阶段或模型不符均不准入。优先采用有效且未过期的 expires_at；缺省时要求 detected_at 在过去60分钟内。

明确故障只来自新鲜匹配模型的检测失败，或有效 v2/1h、足样本且低于门槛的成功率。缺数据、非1h、过期、未知、名单和倍率限制不单独触发故障转移。

## 唯一质量算法

先准入，再在同模型池内分别计算平均并列分位：综合分 = 成功率×40% + 缓存命中×30% + TPS×20% + 低倍率×10%（各项为分位分）。

成功、缓存、TPS越高越好，倍率越低越好。N>1时分位为100×(平均排名−1)/(N−1)，单候选各项100，全并列各项50。平手依次比较实际成功率、缓存、TPS、有效倍率和组ID。分数仅在同轮同模型池有意义。

当前组ID确定模型池，绝不跨模型比较相对分数。正常模式沿用确认与保持；仅故障模式正常时不择优、不自动切回，故障目标仍按相同算法。回滚和故障隔离遵守监控范围。

## 工作台

桌面宽面板支持全屏，窄屏适配；监控、统计、诊断、设置分区。首页支持搜索、平台、可用性、检测状态组合筛选，按质量、倍率、成功率、缓存、TPS排序。显示过滤不改变范围与自动算法，质量排序按模型分池。

详情显示模型、完成/有效期、样本、阶段和拒绝原因。支持键盘、Enter展开、Esc关闭详情/弹窗、深浅色和减少动态。刷新中和错误保留上次数据，空结果提供重置筛选或范围设置入口。

## 验证边界

localhost夹具仅模拟账户、密钥和切组，不等于真实网关、推理或线上运行验证。公开接口只读字段核验与本地模拟证据分开记录。用户明确验收前保持待验收，不自动发布。
