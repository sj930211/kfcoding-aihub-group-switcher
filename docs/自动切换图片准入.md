# 自动切换图片准入

状态：SELF_VERIFIED / PASS。唯一需求与验证记录；用户已授权提交、推送并发布0.18.0，本文件记录发布前验收。未授权真实计费测试。

## 已确认需求

用户确认：图片分退出三种策略及列表排序；策略选出目标后，当前图片有效分必须严格大于配置门槛才能自动切换。无图、无有效分、未达标均按配置分钟临时拉黑并继续选组。有图无缓存时用已选密钥、模型自动评分（计费），失败后拉黑。列表增加逐组切换按钮；手动指定目标跳过图片准入。

## 实现契约

- 仅AIHub应用图片准入，其他站点保留原流程。省钱、稳定、均衡公式及原有平局规则不变，移除15%图片排序权重。
- 门槛默认为80分，范围0至100，严格大于；100表示无图可通过。无评分配置时自动准入失败，手动指定目标仍可用。
- 使用当前原图MD5、字节数、模型、任务、规则缓存；图片替换不沿用旧分；低证据充分性视为无可采用评价。
- 保持期、连续确认尚未达到以及当前组已是推荐时不调用模型；实际自动回退、回滚和立即策略切换均执行准入。
- 手动指定目标（列表按钮、原手动弹窗）跳过图片检查，沿用密钥启用、账号可选与切换后读取校验。
- 同一轮所有密钥共享最多10次新分析预算，缓存不占预算；人工批量评分最多2并发。停止、设置/目录变化、任务繁忙、预算耗尽不误拉黑。预算耗尽停止本轮择组并保持当前状态；之前成功切换的密钥不回滚。
- 共享临时黑名单沿用目标模型组合+分组身份与分钟数，后续密钥不能重复选择刚拉黑的组；到期重新参与策略。全部未通过保持原组。
- 请求过程中变更设置、停止或变更目录取消本次切换；等待评分期间密钥分组在其他页面改变时不覆盖。
- 列表保持48px两行；按钮有禁用、当前使用、忙碌和键盘焦点状态。不改原图片评分规则及缓存空间，不引入依赖。
